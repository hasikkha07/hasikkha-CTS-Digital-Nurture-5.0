# Merge Sort

## Overview

Merge Sort is an efficient divide-and-conquer sorting algorithm. It divides the array into smaller subarrays, sorts them recursively, and then merges them to produce a sorted array.

## Conclusion

Merge Sort is a stable sorting algorithm with guaranteed O(n log n) performance. It is widely used for sorting large datasets and linked lists.
