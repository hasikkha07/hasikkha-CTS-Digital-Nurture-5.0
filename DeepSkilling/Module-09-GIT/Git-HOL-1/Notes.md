# Git HOL-1 Notes

## What is Git?

Git is a distributed version control system that helps developers track changes in source code.

## Features

- Version Control
- Branching
- Merging
- Collaboration
- History Tracking

## Git Configuration

Git stores user information such as:

- Username
- Email Address

## Commands

git --version

Displays the installed Git version.

git config --global user.name

Displays the configured username.

git config --global user.email

Displays the configured email address.

git config --list

Displays all Git configuration settings.

## Conclusion

Git configuration is the first step before using Git repositories.
