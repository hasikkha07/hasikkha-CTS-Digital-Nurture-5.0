# Angular Hands-on Notes

## Objective

Build a Student Management System using Angular.

---

## Components Created

Navbar

Provides navigation links.

Footer

Displays application footer.

Home

Landing page of the application.

Student List

Displays students using StudentService.

Course List

Displays available courses.

Student Profile

Displays profile information.

---

## Service Used

StudentService

Methods

getStudents()

Returns list of students.

---

## Angular Concepts Practiced

- Angular CLI
- Components
- Routing
- Services
- Dependency Injection
- Navigation
- Standalone Components
