# Git HOL-2 Notes

## Git Repository

A Git repository stores all project files and tracks every change made to them.

## Working Directory

The working directory contains the current files being edited.

## Staging Area

The staging area stores selected changes before they are committed.

## Commit

A commit is a snapshot of the project at a specific point in time.

## Commands

### Initialize Repository

git init

Creates a new Git repository.

### Check Status

git status

Displays the current state of the repository.

### Stage Files

git add .

Stages all modified and new files.

### Commit Changes

git commit -m "Initial Commit"

Saves the staged changes.

### View History

git log

Displays the commit history.

## Conclusion

Git tracks changes efficiently by using repositories, staging, and commits.
