# Git HOL-3 Notes

## What is a Branch?

A branch is an independent line of development in Git that allows developers to work on new features without affecting the main codebase.

## Benefits of Branching

- Parallel development
- Feature isolation
- Safe experimentation
- Easy collaboration

## Commands

### View Branches

git branch

### Create a Branch

git branch feature

### Switch Branch

git checkout feature

### View Commit History

git log --oneline

## Conclusion

Git branching enables multiple features and bug fixes to be developed independently before merging into the main branch.
