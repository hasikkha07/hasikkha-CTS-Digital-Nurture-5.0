# Git HOL-2: Git Repository, Staging and Commit

## Aim

To learn how to initialize a Git repository, stage files, commit changes, and view commit history.

## Objectives

- Initialize a Git repository
- Check repository status
- Stage files
- Commit changes
- View commit history

## Commands Used

```bash
git init
git status
git add .
git commit -m "Initial Commit"
git log
```

## Files Used

- index.html
- style.css
- script.js

## Output

The repository was successfully initialized, files were staged, committed, and the commit history was displayed.
