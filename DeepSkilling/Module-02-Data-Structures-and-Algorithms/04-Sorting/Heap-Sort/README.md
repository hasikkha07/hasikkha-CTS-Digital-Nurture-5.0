# Heap Sort

## Overview

Heap Sort is an efficient comparison-based sorting algorithm that uses the Binary Heap data structure. It first builds a Max Heap and then repeatedly extracts the largest element to produce a sorted array.

## Conclusion

Heap Sort provides consistent O(n log n) performance and is suitable for large datasets. It is an in-place sorting algorithm but is not stable.
