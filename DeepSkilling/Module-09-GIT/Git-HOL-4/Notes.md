# Git HOL-4 Notes

## What is Merge?

Merge combines changes from one branch into another.

## Types of Merge

- Fast Forward Merge
- Three-Way Merge

## Advantages

- Combines completed work
- Maintains project history
- Supports collaborative development

## Commands

### Merge a Branch

git merge feature

### View Commit History

git log --oneline --graph

## Conclusion

Git merge integrates feature development into the main project while preserving commit history.
