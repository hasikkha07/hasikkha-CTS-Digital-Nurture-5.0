# Insertion Sort

## Overview

Insertion Sort is a simple comparison-based sorting algorithm that builds the sorted array one element at a time. It works by taking one element from the unsorted portion and inserting it into its correct position in the sorted portion.

## Conclusion

Insertion Sort is efficient for small or nearly sorted datasets. It is simple to implement and performs better than Bubble Sort for partially sorted arrays.
