# Module 08 - Angular

## Objective

This module introduces Angular, a TypeScript-based front-end framework used for building dynamic Single Page Applications (SPAs). It covers Angular project creation, components, routing, services, dependency injection, and basic application development.

---

## Topics Covered

- Introduction to Angular
- Angular CLI
- Project Structure
- Components
- Templates
- Data Binding
- Directives
- Routing
- Services
- Dependency Injection
- Standalone Components
- Navigation
- Angular Application Development

## Learning Outcomes

After completing this module, you will be able to:

- Create Angular projects using Angular CLI.
- Understand Angular folder structure.
- Develop reusable components.
- Configure routing between pages.
- Create and inject services.
- Build simple Angular applications.
- Run Angular applications locally.
