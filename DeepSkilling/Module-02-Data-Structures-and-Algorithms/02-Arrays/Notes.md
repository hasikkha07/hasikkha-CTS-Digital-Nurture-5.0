# Arrays Notes

## What is an Array?

An array is a linear data structure that stores multiple elements of the same data type in contiguous memory locations.

Example

10 20 30 40 50

---

## Features

- Fixed Size
- Same Data Type
- Indexed Collection
- Fast Random Access

---

## Array Representation

Index

0 1 2 3 4

Value

10 20 30 40 50

---

## Traversal

Traversal means visiting every element exactly once.

Example

for loop

foreach loop

Time Complexity

O(n)

---

## Searching

Searching finds an element inside the array.

Example

Linear Search

Time Complexity

O(n)

Binary Search (Sorted Array)

Time Complexity

O(log n)

---

## Insertion

Insert an element at a specific position.

Time Complexity

O(n)

---

## Deletion

Remove an element from the array.

Time Complexity

O(n)

---

## Advantages

- Easy to implement
- Fast element access
- Less memory overhead
- Cache friendly

---

## Disadvantages

- Fixed size
- Costly insertion
- Costly deletion

---

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Access | O(1) |
| Search | O(n) |
| Insert | O(n) |
| Delete | O(n) |
| Traverse | O(n) |

---

## Applications

- Storing student records
- Searching data
- Matrix implementation
- Dynamic Programming
- Sorting Algorithms

---

## Key Takeaways

✔ Arrays store elements in contiguous memory.

✔ Elements are accessed using indices.

✔ Random access takes O(1).

✔ Insertion and deletion require shifting elements.

✔ Arrays are the foundation of many data structures.
