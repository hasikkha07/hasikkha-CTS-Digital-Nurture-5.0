# 03 - Views and Indexes

## Overview

This exercise demonstrates the creation and usage of SQL Views and Indexes. Views simplify complex queries by acting as virtual tables, while indexes improve query performance by enabling faster data retrieval.

---

## Learning Objectives

- Create SQL Views
- Query data through Views
- Update records using Views
- Create Non-Clustered Indexes
- Create Composite Indexes
- View existing indexes
- Drop indexes

---

## Concepts Covered

### Views

- CREATE VIEW
- ALTER VIEW
- Querying Views
- Updating through Views

### Indexes

- Non-Clustered Index
- Composite Index
- Query Optimization
- Index Management

---

## Output

The script creates views, retrieves student information, updates data through a view, creates indexes for optimization, and displays existing indexes.

---

## Conclusion

Views improve code reusability and simplify data access, while indexes significantly improve query performance for frequently searched columns.
