# Linked Lists

## Overview

This section covers Linked Lists, one of the fundamental linear data structures used for dynamic memory allocation. Unlike arrays, linked lists store elements in nodes connected by pointers, allowing efficient insertion and deletion operations. This module includes Singly Linked List, Circular Singly Linked List, Doubly Linked List, and Circular Doubly Linked List.

## Time Complexity Comparison

| Operation | Singly | Circular Singly | Doubly | Circular Doubly |
|-----------|--------|-----------------|---------|-----------------|
| Insert Beginning | O(1) | O(1) | O(1) | O(1) |
| Insert End | O(n) | O(n) | O(n) | O(1) |
| Delete | O(n) | O(n) | O(n) | O(n) |
| Search | O(n) | O(n) | O(n) | O(n) |
| Traverse | O(n) | O(n) | O(n) | O(n) |
