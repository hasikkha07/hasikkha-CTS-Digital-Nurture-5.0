# DDL and DML

## Objective

Understand SQL Server basics and learn Data Definition Language (DDL) and Data Manipulation Language (DML) commands.

---

## SQL Server

Microsoft SQL Server is a Relational Database Management System (RDBMS) used to store, retrieve and manage data.

It uses Transact-SQL (T-SQL).

SQL Server Management Studio (SSMS) is the graphical tool used to execute SQL queries.

---

## DDL Commands

- CREATE
- ALTER
- DROP
- TRUNCATE

DDL commands define and modify database objects.

---

## DML Commands

- INSERT
- UPDATE
- DELETE

DML commands manipulate the data stored inside tables.
