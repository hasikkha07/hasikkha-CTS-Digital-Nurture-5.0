# 06 - Stored Procedures and User Defined Functions

## Overview

This exercise demonstrates the implementation of Stored Procedures and User Defined Functions (UDFs) in SQL Server. Stored Procedures allow reusable SQL logic, while UDFs return computed values or tables for use in SQL queries.

---

## Learning Objectives

- Create Stored Procedures
- Execute Stored Procedures
- Pass Parameters to Procedures
- Create Scalar Functions
- Create Table-Valued Functions
- Retrieve data using UDFs

---

## Concepts Covered

### Stored Procedures

- Procedure without parameters
- Procedure with parameters
- EXEC statement

### User Defined Functions

- Scalar Function
- Table-Valued Function
- RETURN statement

---

## Technologies Used

- SQL Server 2022
- SQL Server Management Studio (SSMS)
- Visual Studio Code

---

## Output

The script creates stored procedures to retrieve student records and user-defined functions to calculate grades and return department-wise student data.

---

## Conclusion

Stored Procedures improve code reusability and security, while User Defined Functions simplify calculations and reusable query logic.
