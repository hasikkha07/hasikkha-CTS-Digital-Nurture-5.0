# Angular Hands-on

## Aim

Develop a Student Management System using Angular to understand project structure, routing, components, and services.

---

## Project Overview

The application demonstrates navigation between multiple pages using Angular Routing.

Pages Included

- Home
- Students
- Courses
- Student Profile

---

## Components

- Navbar
- Footer
- Home
- Student List
- Course List
- Student Profile

---

## Services

StudentService

Responsibilities

- Stores student data
- Returns student list
- Demonstrates Dependency Injection
