# Module 02 - Data Structures and Algorithms

## Overview

This module focuses on the fundamental concepts of Data Structures and Algorithms (DSA), which are essential for developing efficient, scalable, and optimized software solutions. It covers algorithm analysis, arrays, searching techniques, sorting algorithms, and linked lists through practical C# implementations.

The module emphasizes understanding algorithm efficiency using time and space complexity analysis while strengthening problem-solving skills through hands-on coding exercises.

## Complexity Summary

### Searching Algorithms

| Algorithm | Best | Average | Worst |
|-----------|------|----------|--------|
| Linear Search | O(1) | O(n) | O(n) |
| Binary Search | O(1) | O(log n) | O(log n) |

---

### Sorting Algorithms

| Algorithm | Best | Average | Worst | Space |
|-----------|------|----------|--------|--------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) |
| Heap Sort | O(n log n) | O(n log n) | O(n log n) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) |

---

### Linked List Operations

| Operation | Complexity |
|-----------|------------|

| Insert End | O(n) |

| Search | O(n) |
