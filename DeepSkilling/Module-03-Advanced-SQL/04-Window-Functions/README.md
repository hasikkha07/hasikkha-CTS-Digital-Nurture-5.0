# 04 - Window Functions

## Overview

This exercise demonstrates SQL Server Window Functions, which perform calculations across a set of rows without grouping the result set. Window functions are commonly used for ranking, numbering, comparisons, and analytical reporting.

---

## Learning Objectives

- Create an Employees table.
- Insert sample employee records.
- Apply ROW_NUMBER().
- Apply RANK().
- Apply DENSE_RANK().
- Divide records using NTILE().
- Compare rows using LEAD() and LAG().
- Partition data by department.

---

## Window Functions Covered

- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- NTILE()
- LEAD()
- LAG()
- PARTITION BY

---

## Technologies Used

- SQL Server 2022
- SQL Server Management Studio (SSMS)
- Visual Studio Code

---

## Output

The queries generate rankings, row numbers, salary comparisons, and departmental rankings using SQL Window Functions.

---

## Conclusion

Window Functions provide powerful analytical capabilities while preserving individual rows, making them ideal for reporting and business intelligence.
