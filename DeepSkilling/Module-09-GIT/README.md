# Module 09 - Git

## Overview

This module focuses on Git, a distributed version control system, and GitHub, a cloud-based platform for hosting Git repositories. It covers the essential Git commands and workflows used in software development.

---

## Objectives

- Understand Version Control Systems.
- Learn Git installation and configuration.
- Create and initialize Git repositories.
- Stage and commit changes.
- Create and manage branches.
- Merge branches.
- Work with remote repositories.
- Push and pull code using GitHub.
