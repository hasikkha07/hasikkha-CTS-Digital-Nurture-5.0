# Module 06 – ASP.NET Core Web API

## Overview

This module introduces ASP.NET Core Web API development. It covers creating RESTful APIs, controllers, routing, model binding, validation, middleware, dependency injection, exception handling, Swagger documentation, and API testing.

---

## Learning Objectives

- Understand ASP.NET Core Web API architecture.
- Create RESTful APIs.
- Implement Controllers and Routing.
- Perform CRUD operations using HTTP methods.
- Apply Model Binding and Validation.
- Use Dependency Injection.
- Implement Custom Middleware.
- Handle Exceptions.
- Document APIs using Swagger.
- Follow REST API Best Practices.
