# Module 08 Notes

## What is Angular?

Angular is a TypeScript-based open-source front-end framework developed by Google for building dynamic Single Page Applications (SPA).

---

## Features of Angular

- Component-Based Architecture
- TypeScript Support
- Dependency Injection
- Routing
- Services
- Two-Way Data Binding
- Directives
- Modular Design
- CLI Support

---

## Angular CLI

Common Commands

Create Project

ng new AngularApp

Run Project

ng serve

Generate Component

ng g c component-name

Generate Service

ng g s service-name

Build Application

ng build

## Routing

Routing allows navigation between different pages without reloading the application.

Example Routes

/

students

courses

profile

---

## Services

Services contain business logic and data.

Benefits

- Code Reusability
- Separation of Concerns
- Easier Maintenance

---

## Dependency Injection

Angular automatically provides services wherever they are needed.

Example

StudentService provides student data to StudentList component.

---

## Advantages of Angular

- Fast Development
- Reusable Components
- Large Community
- Strong Type Checking
- Easy Routing
- Powerful CLI

## Conclusion

Angular simplifies front-end development by combining components, routing, and services into a structured application architecture.
