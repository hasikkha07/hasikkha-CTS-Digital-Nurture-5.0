# 02 - Joins and Subqueries

## Overview

This exercise demonstrates how to retrieve related data from multiple tables using SQL Joins and Subqueries.

## Objectives

- Create relational tables
- Use Primary and Foreign Keys
- Perform INNER JOIN
- Perform LEFT JOIN
- Perform RIGHT JOIN
- Perform FULL OUTER JOIN
- Perform CROSS JOIN
- Perform SELF JOIN
- Write Subqueries
- Use EXISTS clause

## Tables Used

- Students
- Courses
- Enrollments

## SQL Concepts Covered

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN
- CROSS JOIN
- SELF JOIN
- Nested Subqueries
- Aggregate Subqueries
- EXISTS

## Output

The queries display student-course relationships and demonstrate different join operations.

## Conclusion

Joins combine records from multiple tables, while subqueries allow nested query execution for complex data retrieval.
