# Module 07 – Microservices Architecture using ASP.NET Core Web API

## Overview

This module introduces the Microservices architectural style using ASP.NET Core Web API. It explains how applications can be divided into small, independent services that communicate with each other. The module also covers authentication, security, monitoring, deployment strategies, and containerization using Docker and Kubernetes.

---

## Learning Objectives

After completing this module, you will be able to:

- Understand the Microservices architecture.
- Compare Monolithic and Microservices architecture.
- Explain the advantages and challenges of Microservices.
- Implement JWT Authentication in ASP.NET Core Web API.
- Understand service communication methods.
- Learn service discovery concepts.
- Understand logging and monitoring.
- Learn deployment strategies.
- Get an introduction to Docker and Kubernetes.
