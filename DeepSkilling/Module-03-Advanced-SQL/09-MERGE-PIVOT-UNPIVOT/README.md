# 09 - MERGE, PIVOT and UNPIVOT

## Overview

This exercise demonstrates advanced SQL operations using MERGE, PIVOT, and UNPIVOT statements. These operations are commonly used for synchronizing tables and transforming data for reporting purposes.

---

## Learning Objectives

- Create source and target tables
- Synchronize data using MERGE
- Convert rows into columns using PIVOT
- Convert columns back into rows using UNPIVOT
- Analyze tabular data efficiently

---

## Concepts Covered

### MERGE

- Insert new records
- Update existing records
- Synchronize tables

### PIVOT

- Convert rows into columns
- Generate summary reports

### UNPIVOT

- Convert columns back into rows
- Normalize pivoted data

---

## Technologies Used

- SQL Server 2022
- SQL Server Management Studio (SSMS)
- Visual Studio Code

---

## Output

The script synchronizes student records using MERGE, summarizes sales data using PIVOT, and restores the original format using UNPIVOT.

---

## Conclusion

MERGE simplifies table synchronization, while PIVOT and UNPIVOT provide powerful tools for reporting and data transformation.
