# Git HOL-3: Branching

## Aim

To understand Git branching and branch management.

## Objectives

- Create a branch
- Switch between branches
- Modify project files
- Commit changes in a branch

## Commands Used

```bash
git init
git add .
git commit -m "Initial Commit"
git branch
git branch feature
git checkout feature
git add .
git commit -m "Added feature page"
git log --oneline
```

## Output

A new feature branch was created, changes were committed, and the branch history was verified.
