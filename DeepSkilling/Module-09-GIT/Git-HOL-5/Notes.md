# Git HOL-5 Notes

## Remote Repository

A remote repository is a Git repository hosted on a server such as GitHub.

## GitHub

GitHub is a cloud-based platform for hosting Git repositories and collaborating with developers.

## Important Commands

### Add Remote

git remote add origin <repository-url>

### View Remote

git remote -v

### Push Changes

git push -u origin branch-name

### Pull Changes

git pull origin branch-name

### Show Remote Details

git remote show origin

## Benefits

- Backup source code
- Team collaboration
- Version tracking
- Easy synchronization

## Conclusion

Remote repositories enable developers to share, back up, and collaborate on projects using GitHub.
