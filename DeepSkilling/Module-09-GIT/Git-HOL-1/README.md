# Git HOL-1: Git Basics

## Aim

To understand Git installation and configure Git user information.

## Objectives

- Verify Git installation
- Configure Git username
- Configure Git email
- Display Git configuration

## Commands Used

```bash
git --version
git config --global user.name
git config --global user.email
git config --list
```

## Output

Git was successfully installed and configured with the global username and email.
