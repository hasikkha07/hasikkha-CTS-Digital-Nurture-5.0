# Sorting Algorithms

## Overview

This section covers the fundamental sorting algorithms used to arrange data in ascending or descending order. Sorting improves the efficiency of searching, data processing, and various algorithmic operations. The module includes Bubble Sort, Insertion Sort, Heap Sort, Merge Sort, and Quick Sort, along with their implementation and complexity analysis.

## Time Complexity Comparison

| Algorithm | Best | Average | Worst | Space | Stable |
|-----------|------|----------|--------|--------|---------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) | Yes |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) | Yes |
| Heap Sort | O(n log n) | O(n log n) | O(n log n) | O(1) | No |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) | Yes |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) | No |
