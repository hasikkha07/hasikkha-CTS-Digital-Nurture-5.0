# Singly Linked List Notes

## What is a Singly Linked List?

A Singly Linked List is a collection of nodes.

Each node contains:

- Data
- Pointer to the next node

---

## Structure

```

Data | Next

```

Example

10 → 20 → 30 → 40 → NULL

---

## Operations

### Insert

Adds a node to the list.

Time Complexity

- Beginning → O(1)
- End → O(n)

---

### Delete

Removes a node.

Time Complexity

O(n)

---

### Search

Searches for a value.

Time Complexity

O(n)

---

### Traverse

Visits every node.

Time Complexity

O(n)

---

## Advantages

- Dynamic Size
- Easy insertion
- Easy deletion
- Efficient memory utilization

---

## Disadvantages

- Sequential access
- Extra memory for pointers
- Slower searching

---

## Applications

- Music playlists
- Browser history
- Undo/Redo
- Polynomial representation
- Memory management

---

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Insert Beginning | O(1) |
| Insert End | O(n) |
| Delete | O(n) |
| Search | O(n) |
| Traverse | O(n) |

---

## Key Takeaways

✔ Dynamic data structure.

✔ Each node stores data and next pointer.

✔ Efficient insertion and deletion.

✔ No random access.

✔ Used in many real-world applications.
