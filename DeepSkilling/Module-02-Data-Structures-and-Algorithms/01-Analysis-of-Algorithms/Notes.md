# Analysis of Algorithms Notes

## What is an Algorithm?

An algorithm is a step-by-step procedure used to solve a problem.

Example:

Searching an element in an array.

---

## Why Data Structures and Algorithms?

- Faster execution
- Better memory usage
- Efficient software
- Better interview preparation

---

## Types of Data Structures

### Linear

- Array
- Linked List
- Stack
- Queue

### Non-Linear

- Tree
- Graph
- Heap

---

## Time Complexity

Time Complexity measures how execution time grows with input size.

Examples

O(1)

Constant Time

O(n)

Linear Time

O(log n)

Logarithmic Time

O(n log n)

Linearithmic Time

O(n²)

Quadratic Time

---

## Space Complexity

Measures how much extra memory an algorithm requires.

---

## Asymptotic Notations

### Big O (O)

Worst Case

Example

Binary Search → O(log n)

### Big Omega (Ω)

Best Case

### Big Theta (Θ)

Average Case

---

## Case Analysis

### Best Case

Minimum execution time.

### Average Case

Average execution time.

### Worst Case

Maximum execution time.

## Key Takeaways

✔ Algorithms solve problems efficiently.

✔ Time Complexity measures execution speed.

✔ Space Complexity measures memory usage.

✔ Big O describes the worst-case performance.

✔ Recursive algorithms use additional stack memory.

✔ Choosing the right algorithm improves application performance.
