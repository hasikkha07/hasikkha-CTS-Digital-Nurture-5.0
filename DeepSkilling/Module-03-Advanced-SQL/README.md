# Module 03 – Advanced SQL

## Overview

This module focuses on advanced SQL concepts using Microsoft SQL Server 2022. It covers database creation, table management, joins, subqueries, views, indexes, window functions, Common Table Expressions (CTEs), stored procedures, user-defined functions, triggers, cursors, transactions, exception handling, and advanced operations such as MERGE, PIVOT, and UNPIVOT.

The hands-on exercises were implemented using SQL Server Management Studio (SSMS) and Visual Studio Code with the SQL Server extension.

---

## Learning Objectives

After completing this module, I was able to:

- Create and manage databases and tables using DDL.
- Perform CRUD operations using DML.
- Retrieve data using Joins and Subqueries.
- Create and manage Views and Indexes.
- Use Window Functions for analytical queries.
- Implement Common Table Expressions (CTEs).
- Develop Stored Procedures and User Defined Functions.
- Implement Triggers and Cursors.
- Handle Transactions and SQL Exceptions.
- Perform MERGE, PIVOT, and UNPIVOT operations.
