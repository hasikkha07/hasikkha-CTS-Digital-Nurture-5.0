# Single Responsibility Principle (SRP)

## Overview

The Single Responsibility Principle states that a class should have only one reason to change, meaning it should have only one responsibility.

In this example:

- `Report` stores report data.
- `ReportPrinter` handles printing.

Each class performs a single task, making the code easier to maintain and extend.
