# 05 - CTE and Recursive CTE

## Overview

This exercise demonstrates the implementation of Common Table Expressions (CTEs) and Recursive CTEs in SQL Server. CTEs simplify complex SQL queries and Recursive CTEs are used to retrieve hierarchical data such as employee-manager relationships.

---

## Learning Objectives

- Create Common Table Expressions (CTEs)
- Retrieve data using CTEs
- Apply filtering within CTEs
- Implement Recursive CTEs
- Display hierarchical employee data
- Count employees under each manager

---

## Concepts Covered

### Common Table Expression (CTE)

- WITH clause
- Temporary result sets
- Query simplification

### Recursive CTE

- Anchor Member
- Recursive Member
- UNION ALL
- Hierarchical Data

---

## Technologies Used

- SQL Server 2022
- SQL Server Management Studio (SSMS)
- Visual Studio Code

---

## Output

The script displays employee records, filters managers using CTEs, generates an employee hierarchy using Recursive CTEs, and counts employees reporting to each manager.

---

## Conclusion

CTEs improve query readability, while Recursive CTEs efficiently solve hierarchical and tree-structured data problems.
