# Module 09 Notes

## What is Git?

Git is a distributed version control system that tracks changes in source code and allows multiple developers to collaborate efficiently.

---

## What is GitHub?

GitHub is a cloud-based hosting platform that stores Git repositories and supports collaborative software development.

---

## Features of Git

- Distributed Version Control
- Fast Performance
- Branching
- Merging
- History Tracking
- Collaboration

## Common Git Commands

### Check Git Version

git --version

### Configure Username

git config --global user.name "Your Name"

### Configure Email

git config --global user.email "your@email.com"

### Initialize Repository

git init

### Check Status

git status

### Stage Files

git add .

### Commit Changes

git commit -m "Commit Message"

### View History

git log

### Create Branch

git branch feature

### Switch Branch

git checkout feature

### Merge Branch

git merge feature

### Add Remote

git remote add origin <repository-url>

### View Remote

git remote -v

### Push Changes

git push origin deepskilling

### Pull Changes

git pull origin deepskilling

---

## Advantages

- Tracks every code change.
- Enables collaboration.
- Supports multiple branches.
- Easy rollback to previous versions.
- Secure backup using GitHub.

---

## Best Practices

- Commit frequently.
- Use meaningful commit messages.
- Pull before pushing.
- Keep repositories organized.
- Use .gitignore for unnecessary files.

---

## Conclusion

Git and GitHub are essential tools for modern software development, providing efficient version control, collaboration, and project management.
